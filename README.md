# The Upgrade Plane
A web-based incremental game where you buy upgrades on an infinite 2D plane.

*Inspired by [upgrade land](https://galaxy.click/play/873)*

## Project Info
This project is **open source**, meaning anybody can view the code and modify it. Credit is appreciated but not required.

As of now, this project is in **early development**, so expect bugs, unbalanced gameplay, and other mistakes.
